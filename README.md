# 数码旅途 · 本地试玩版 0.2

面向手机竖屏的数码兽卡牌冒险，支持三章探索、卡组构筑、成熟期分支进化与跨局扫描收集。早期策划中的后续设想不代表已实现，以本文与「本轮开发说明.md」为准。

## 开始试玩

```sh
npm install
npm run dev
```

电脑访问 http://localhost:5177/ 。手机与电脑连接同一 Wi-Fi，访问启动时显示的 Network 地址；电脑需保持运行。不同浏览器、不同访问地址分别保存进度。

`npm run build` 生成 `dist/`，`npm run preview` 检查构建结果。不支持直接双击 HTML 运行。

## 已实现内容

| 系统 | 本版内容 |
| --- | --- |
| 地图 | 三章共24层，由下向上探索；真实连线约束通行，点击亮起节点直接出发、当前位置定位 |
| 搭档 | 基尔兽、妖狐兽，两套初始牌组 |
| 进化树 | 横向四阶段、成熟期开始分叉；共15种形态、5个究极体终点，可随时查看与追踪目标 |
| 专属技能 | 到达对应形态后解锁奖励／商店卡池；后续进化保留并标记为继承技能，未走过的分支不解锁 |
| 进化条件 | 阶段里程碑＋本局攻击、防御、技能系列等行为；特殊路线另需跨局资料 |
| 进化收益 | 形态被动、两张自选卡转换且保留强化、训练与能力继承；可暂缓并在营地补进化 |
| 卡组 | 随时查看永久卡组；战斗中查看手牌、抽牌堆、弃牌堆、耗竭区；类型筛选、排序、费用分布、强化预览 |
| 卡牌 | 45种可用牌及1种故障牌；攻击、防御、灼烧、符印、复制、自损、吸血等 |
| 同步 | 究极体消耗6点同步开启三回合爆发，每场一次 |
| 节点 | 普通战斗、精英、首领、营地、商店、事件、宝箱、进化 |
| 敌人 | 12种普通敌人、6种精英、3位首领，显示行动意图 |
| 扫描 | 15种可扫描对象，同场同种只计一次；普通／精英胜利＋50%，首领＋100% |
| 支援 | 齿轮兽、蘑菇兽、小恶魔兽扫描100%可转化；战斗外装备，每场使用一次 |
| 跨局路线 | 邪龙兽扫描100%解锁混沌资料；狮子兽扫描100%或第二章安全净化事件解锁净化资料 |
| 道具图鉴 | 顶部背包入口，按装置／祝福／消耗品筛选；展示10项效果、来源及本局持有状态 |
| 其他 | 6种装置、3种祝福、恢复磁盘、卡牌强化／移除 |
| 存档 | 每次操作自动保存，保留手牌、行为与随机状态；失败保留扫描和路线资料；可下载JSON备份 |

战斗操作：点手牌查看详情，需要指定目标时点击敌人，再点「卡片抽换」。手牌横向滑动，结束回合前可使用支援或恢复磁盘。抽牌堆按名称／费用排序展示，不暴露真实抽取顺序。

## 存档迁移

存档版本升级为2，沿用 `digimon-journey-v1` 存储键。首次迁移前把旧JSON备份到 `digimon-journey-v1-before-v2`。保留已有形态、卡组、手牌、生命、图鉴及随机状态；补齐地图连线和可推断的首领／胜利进度。新增行为从0开始，不伪造历史。旧版停留在究极体选择界面的存档保留原有四条选择，新混沌路线仍需满足条件。

## 当前边界

- 尚无全物种主搭档、退化重构、合步进化或双主搭档；仅三种扫描对象可作为支援。
- 33套像素动画素材之外，黑古拉兽、妖狐兽（蓝）、道士兽暂用官方静态立绘；尚无完整独立攻击／受击动画。
- 无账号、云存档、联网对战、离线安装或存档导入。当前数值仍需更多人工通关调优。
- Node26构建工具存在一条弃用提示，不影响已验证的构建与运行。

## 形态专属技能更新

「阴阳术」「金刚结界」需到达祭师兽；「咒符结界」需到达道士兽。已解锁卡池在本局后续进化时保留，下局重新解锁。通用卡不受限制。卡面新增通用／专属／继承／未解锁／旧版保留标记，详情说明来源形态；进化树展示该形态解锁的完整专属卡池。

初始与赠送技能的来源同步校正：岩石粉碎属于基尔兽，符咒与解印属于妖狐兽，烈焰引爆属于古拉兽，血色利刃属于黑古拉兽，危险过载属于黑大古拉兽。以上是本游戏的技能归属配置，不声称复刻官方招式表。妖狐兽（蓝）的进化赠牌改为焰玉咒、狐变虚，咒符结界留至道士兽解锁。

旧存档已拥有的牌保留可用；未解锁的旧卡不能让整个形态卡池提前开放。旧档中尚未领取／购买的提前技能会替换成合法候选，保留已购记录、卡组、强化、生命和随机状态。

本次74项测试与构建通过，包含原有四路线完整通关、新增8项技能解锁／旧档兼容测试；组件输出验证了未解锁→专属→继承标记及原卡面。浏览器连接暂不可用，此次新增标记尚未完成手机实机或浏览器视觉验收。
