# 数码旅途 · 本地试玩版 0.2

面向手机竖屏的数码兽卡牌冒险，支持三章探索、卡组构筑、成熟期分支进化与跨局扫描收集。早期策划中的后续设想不代表已实现，以本文与「本轮开发说明.md」为准。

## 开始试玩

```sh
npm install
npm run dev
```

电脑访问 http://localhost:5177/ 。手机与电脑连接同一 Wi-Fi，访问启动时显示的 Network 地址；电脑需保持运行。不同浏览器、不同访问地址分别保存进度。

`npm run build` 生成 `dist/`，`npm run preview` 检查构建结果。不支持直接双击 HTML 运行。

## 发布到 GitHub Pages

在仓库的 Settings → Pages 中，将 Build and deployment 的 Source 设为 **GitHub Actions**。推送到 `main` 后，`.github/workflows/deploy.yml` 会安装依赖、按 `/digimon-card-roguelike/` 路径构建，并发布 `dist/`。可在 Actions 页面查看部署结果；不要选择从 `main` 根目录直接发布，那里是需要构建的源码。

战斗操作：第一次点击手牌选中卡片，第二次点击同一张牌直接使用；也可点击「使用」按钮。需要指定目标时先点击敌人。出牌与敌方行动按顺序播放简短动效，命中时结算；手牌横向滑动，结束回合前可使用支援或恢复磁盘。抽牌堆按名称／费用排序展示，不暴露真实抽取顺序。

首页操作：点击三个搭档选择位切换角色与玩法介绍，再点击「与搭档出发」进入旅途祝福；查看进化路线会打开当前选中的搭档。有进行中的冒险时，首页展示当前形态、章节、生命和卡组，点击「继续冒险」返回原进度。伙伴图鉴、道具图鉴与玩法说明位于主操作下方，设置保留在顶部。手机短屏优先展示选择与出发，辅助入口可向下滚动查看。

旅途交互：商店、事件、营地与战后奖励统一先预览、再明确执行。删牌／强化使用独立选牌面板，支持类型筛选、完整效果与强化前后对比；取消不扣费且保留原页面位置。手机版固定金币／生命状态和底部确认、取消或离开入口；不足金币、满容量与已购状态直接说明原因。恢复磁盘购买后进入库存，在战斗中使用回血；营地显示实际回复量，满血不消耗恢复行动，可直接离开。扫描详情可展开，跳过卡牌仍保留金币、扫描和已转化伙伴。详见 [手机版旅途交互优化](./手机版旅途交互优化.md)。

## 形态专属技能更新

「阴阳术」「金刚结界」需到达祭师兽；「咒符结界」需到达道士兽。已解锁卡池在本局后续进化时保留，下局重新解锁。通用卡不受限制。卡面新增通用／专属／继承／未解锁／旧版保留标记，详情说明来源形态；进化树展示该形态解锁的完整专属卡池。

初始与赠送技能的来源同步校正：岩石粉碎属于基尔兽，符咒与解印属于妖狐兽，烈焰引爆由古拉兽／黑古拉兽共享，血色利刃属于黑古拉兽，危险过载属于黑大古拉兽。以上是本游戏的技能归属配置，不声称复刻官方招式表。妖狐兽（蓝）的进化赠牌改为焰玉咒、狐变虚，咒符结界留至道士兽解锁。

旧存档已拥有的牌保留可用；未解锁的旧卡不能让整个形态卡池提前开放。旧档中尚未领取／购买的提前技能会替换成合法候选，保留已购记录、卡组、强化、生命和随机状态。

本次74项测试与构建通过，包含原有四路线完整通关、新增8项技能解锁／旧档兼容测试；组件输出验证了未解锁→专属→继承标记及原卡面。浏览器连接暂不可用，此次新增标记尚未完成手机实机或浏览器视觉验收。

## 卡牌平衡第一轮校准（2026-10-09）

全部60张卡使用独立强化配置，卡面与结算共用最终数值。紧急分析＋保持1费抽3；狐变虚＋保持1费、可指定复制目标，所有复制来源每回合合计最多2次；地狱咆哮＋保持1费、灼烧7；数据修复＋保持1费、治疗8。五张原本强化无收益的零费功能牌提升抽牌或返能，仍保留耗竭。双刃斩＋／狐叶楔＋调整为7×2／5×2；重装齐射改为12＋6×蓄能，三蓄能基础伤害30。

校准采用正式引擎计算实际伤害、防伤、治疗、净能量与后续状态增量，避免过量防御与资源消费重复估值。详见 [卡牌平衡校准公式](./卡牌平衡校准公式.md)。第一轮归档为 [59张牌、502项场景报告](./reports/card-balance-round1.md)；系数是第一轮筛查起点，后续仍需人工体验和跨种子统计校准。

154项测试、类型／静态检查、生产构建通过，包含四类资源循环与七个终点的既有通关回归。浏览器验证复制选择、取消不扣费、无目标／上限提示、实际返能、炮击、旧档与刷新恢复；390／360px复制弹窗无整页横向溢出。验收夹具为 `tests/manual/balance.html`，只在5179端口写测试存档。v1／v2旧档保留卡组与进度，旧档缺失复制计数时从0开始；已有强化牌采用本轮新效果。
