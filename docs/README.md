## 维护约定

- 新增项目说明放入对应子目录，并更新本索引；根 README 只保留试玩、开发、发布与文档入口。
- 当前规则变更先更新 `项目说明.md`，再按需要同步公式与交互说明；历史报告保留原始结果，并标明适用版本。
- 文档链接相对当前文档位置；代码路径与命令均相对仓库根目录。
- 审核工具输出到 `docs/reports/`，素材检查记录输出到 `docs/assets/`。默认使用 `latest`，新验证使用新的标签，避免覆盖历史样本。
- 第三方原始说明、校验清单及随构建发布的来源声明继续保留在 `assets/` 与 `public/`。
