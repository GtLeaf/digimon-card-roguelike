# 卡牌平衡校准公式 v3（唯一现行口径）

更新：2026-10-09。适用当前五章、103张可用牌版本。实现只有 `src/game/balance.ts`；`scripts/cardAudit.ts` 已移除静态权重、手写强化推断和全局组合配对，仅转发到同一个审核入口。历史报告保留作追溯，不是另一套现行标准。

## 一、主公式

```
U = D + 1.25P + 2H + 3Q + 7ΔE + ΔF − 2L − 3N
```

| 项 | 口径 |
| --- | --- |
| D | 正式引擎反馈的敌方实际生命损失；排除格挡和过量伤害 |
| P | 出牌前后分别立即结束回合，比较玩家实际承伤之差；护盾、虚弱、击杀、打断只记一次 |
| H / L | 本次实际回复 / 失去的生命；满血不计治疗，自损按实际扣血 |
| Q | 每一步新入手的非故障牌数量，包含复制；受真实手牌上限限制 |
| ΔE | 结算后的行动力差，含支付和返能；不再重复扣费用 |
| ΔF | 结算前后资源池价值之差；生产加存款，消费扣存款 |
| N | 实际成功出牌数；每张计3点出牌位置成本 |

全部强化读 `cardDefinition`，全部支付读 `playCost`。觉醒斗牛士兽第二张攻击、升级减费和零费牌均按真实规则计算，不做“零费折算0.5费”。单牌和序列只使用同一公式；任一步非法就报告步骤，不提交部分结算。

终局：Q与后续资源为0；ΔE取负的实际累计支付，未使用返能不加分。直接死亡、结束回合后死亡、胜利均单列，不能被高分掩盖。

**系数仍是筛查假设，不是假称已拟合的最优权重。** 1行动力≈7点源于基础攻击，其他系数沿用当前生存/调度偏好；没有新增玩家样本时，优先修正漏算、重复计价和场景错误，而不任意更换系数。

## 二、后续资源 ΔF

```
F = 灼烧 + 符印 + 蓄能 + 噬能 + 易伤 + 下一次攻击增益 + 力量
ΔF = F(结算后) − F(结算前)
```

默认前瞻3次、灼烧折现0.8。初末状态分别检查手牌、抽牌堆和弃牌堆；耗竭牌不能充当出口，不按隐藏抽牌顺序预测。没有相应出口时资源不虚构收益。可显式传入同一场景参数进行敏感性比较，但不能绕过出口存在性。

| 资源 | v3估计 |
| --- | --- |
| 灼烧 | 每个敌人独立累加 `max(层数−t,0)×0.8^t`，按剩余HP截断；在敌人攻击后结算，不预先计防伤 |
| 符印 | 层数×牌组可用解印的最高真实倍率×0.6；符印碎击读4，其他出口读自身倍率，不能统一写5 |
| 蓄能 | 识别普通炮击、巨型导弹的逐段蓄能、爆炎射击的持有奖励；通过有/无蓄能的引擎试算差额估值 |
| 噬能 | 识别伤害、追加段数、力量、易伤、护盾、虚弱、治疗出口；使用同一出口的有/无噬能差额，反映阈值、上限、耗竭与形态被动 |
| 易伤 | 实际易伤×预计命中段数×0.8；仅估计后续攻击机会，递减过程仍是近似 |
| 下一次攻击增益 | 有/无追加段数或伤害的实际试算；只看本回合手里仍付得起的攻击，不能把下回合才抽到的牌当成收益 |
| 力量 | 力量×预计后续命中段数，上限6段；单体多段不乘敌人数，群攻逐目标计段，散射在目标间分摊 |

蓄能/噬能的兑现系数：有手中可支付出口为1，只有牌堆出口为0.75，无出口为0。该系数是场景假设，不是统计概率。

复杂出口在**隔离副本**中比较有资源与清零资源两种情况，最多重复同一可循环出口3次，耗竭/复制品只试1次。试算会补足费用并取出该牌，因而表示“出口潜力”，**不表示当前存在这段合法连招**。其他资源清零以减少重复归因；保留真实形态与被动。只取一个出口的最高潜力，不把同一份噬能同时兑换成所有收益。机会系数统一折减此潜力。

伤害价值逐敌共享剩余HP预算，按灼烧→符印→蓄能→噬能→下一次攻击增益→易伤→力量分配。资源带来的治疗、防伤另共享缺血和即将承伤预算。这个分配顺序是固定近似，不能当作最优出牌计划。

## 三、报告必须同时显示的边界

- U是当前场景下的增量筛查值，负数不等于废牌，也不能据此将成长期牌与究极体牌排在一张强度榜上。
- `unpricedEffects` 单列噬能上限提升、耗竭减薄、故障清除、复制选择、破盾、后续虚弱、同步/爆发变化；进化进度和跨战斗成长也不压成固定分数。
- 抽牌按实际到手计3点，未根据牌组质量和当前费用细化；短战/长战、随机散射、护卫目标分配、一次性单体解印的多目标调度等仍需看实际序列。
- 三次同出口估计偏乐观，且其他资源清零会漏掉资源间的协同。治疗、自损、敌方亡语等组合仍须检查真实结果，不能仅靠资源池排名。
- 持久力量只有有限段数估计；易伤衰减为折现近似；容量提升不会凭空获分。不得因这些牌分数偏低就自动增强。
- 旅途模拟中的行动/选牌偏好是测试机器人策略，不是另一套卡牌平衡公式；其胜率不等于玩家胜率。

## 四、现行审核流程

1. 单牌：基础/强化、1/2/3敌、普通/多段攻击，通用牌在8个形态场景；所有补充出口验证本局进化历史。
2. 条件：噬能与蓄能0/3/6，护盾0/10/20/30，自损先后手、谢幕攻击后返能、满血治疗、无补充出口，以及短/长战参数。
3. 组合：同一U评估真实合法序列；循环另行验证，不用高低分判定循环安全。
4. 定向循环：神乐铃＋、饭纲＋、谢幕回旋及其强化版；120步不补牌/补能，检查同回合资源不下降，并尝试插入终结牌。达到上限仅称持续循环风险见证，不能冒充数学证明。基础铃/饭纲、耗竭返能牌作为有限对照。
5. 下一轮实战：先控制无限循环，再对弱牌做小批量调整；用同一策略、种子和获取预算评估失血、战斗时长、选取率、跳过率和路线达成率。
