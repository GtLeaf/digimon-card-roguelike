# 当前卡牌平衡 Review

日期：2026-10-09。对象为当前工作区（含已有未提交变更），五章、103张可用牌＋1张故障牌。本次仅审核，未修改游戏数值或规则。证据脚本保存被测源文件SHA-256，后续改动请重新运行。

结论：现有状态差额公式适合作为单牌筛查的基础，但两套工具的口径不统一，且未完整覆盖新机制。目前不能称为整体平衡；已确认三组无资源衰减的循环、两张缺少竞争力的究极体牌，以及若干需要单独验证的强化收益异常。

## 1. 优先修复的确定问题

### P1：三组无限循环不受复制限制

下面使用5张牌的独立战斗夹具，校验形态技能归属后，只通过正式出牌规则执行，没有中途补能量、补手牌或改计数。两张同名强化牌需要实际获取与两次强化，薄牌组也有整理成本；本次证明的是组合一旦成立可循环，不是每局都能拿到，也未以完整旅途验证这三套牌组的获取率。

| 组合 | 120次循环操作结果 | 可兑现收益 |
| --- | --- | --- |
| 神乐铃＋×2、碎符、防御插件×2；妖狐兽→妖狐兽（蓝）→道士兽→沙古牙兽 | 仍在第1回合，生命60不变，行动力3不变，符印0→240 | 再打一张0费碎符，100生命目标死亡；并不需要刷到120次才可击杀 |
| 式神·饭纲＋×2、碎符、防御插件×2；道士兽→葛叶兽 | 仍在第1回合，行动力3不变，可持续互相抽回 | 穿插碎符持续造成伤害；后续63次出牌击杀目标，未结束回合 |
| 谢幕回旋＋×2、攻击指令、防御插件×2；斗牛士兽·觉醒 | 先攻击一次，再循环120次，行动力2→122，生命不变 | 循环中穿插攻击指令即可击杀目标，未结束回合 |

原因：升级同时获得0费、可循环抽牌，且没有耗竭或相关触发上限。谢幕回旋在攻击后还返还能量。抽牌堆为空时弃牌堆立即洗回，两张牌能互相回收。三组均未复制任何牌，复制次数始终为0。行为统计上限只限制进化进度，不限制战斗效果。

位置：`src/game/cardUpgrades.ts:167`、`:181`、`:386`；结算见`src/game/battle.ts:246`、`:638`、`:649`、`:879`。

建议：先阻断循环，再调数值。神乐铃＋可先保留1费、以抽2作为强化收益；饭纲＋可保留1费，或让0费版本耗竭；谢幕回旋需要同时约束抽牌与返能，例如耗竭，或保留费用并将返能限定每回合首次。只给返能加限制却保留0费无限抽牌，仍可配合其他0费牌循环。上述均是候选修法，尚未实施或验证修改后的平衡。

### P1：静态评分脚本没有使用真正的强化结果

`scripts/cardAudit.ts:37`自行推算伤害、抽牌、费用，未调用`cardDefinition`。例如紧急分析＋会被旧规则当成0费，但当前实际为1费抽3；神乐铃＋、谢幕回旋＋则因旧`upgradeText`分支被当成1费，实际是0费。异常标记只检查基础版满载分，升级后是否失衡也没单独触发告警。

此外，脚本把0费视为0.5费；以固定群攻倍率1.8、统一专属溢价4.5混合比较不同阶段；单牌消费资源不扣储备价值。它不能准确识别免费循环，也容易把正常究极体成长判成超标。

组合挑选在全卡池选择“最优产出牌”，没有限定同一合法进化历史。现有报告甚至把沙古牙兽的净化之印与葛叶兽的胎藏界曼荼罗配对；目前没有退化／跨究极体换线，二者不能在正常同一局共同解锁。成长期消费牌用究极体产出牌来证明合格，也掩盖了前中期的问题。

建议停止用这套脚本的“异常”标记直接决定加减数值。基础／强化统一读正式定义，按合法形态历史、阶段、真实成本和资源准备过程比较。

### P1：真实结算公式遗漏新资源，样本又缺少关键场景

`src/game/balance.ts:73`的未来资源池只有灼烧、符印、蓄能、力量。噬能、易伤、噬能上限、下次攻击加段未估值；产生这些效果常被低估，消耗噬能则不会扣除原资源价值。

去除无关首牌被动后，实际测试中以下四张强化牌都获得U=-3、未来价值0，但分别真实产生2噬能、3噬能且提高上限、2易伤、下次攻击＋2段：恶作剧＋、噬能光环＋、噬能侵蚀＋、风压推进＋。这是模型未覆盖，不能作为削弱或增强它们的证据。

还有三处具体偏差：

- `contextualBalanceOptions`把单体攻击的预计段数也乘以敌人数；只有群攻才应这样放大。蓄能出口只识别`special==='cannon'`，遗漏巨型导弹的`chargeSeg`消费。
- 符印池固定每层5伤害，但碎符实际每层4；消费出口与倍率需要一起估计。
- `calibrateSequence`累计的是牌面费用，终局将其全扣掉。觉醒斗牛士兽第二张攻击实际免费，测试中1点生命目标的致死攻击却仍被扣1费，分数凭空少7；应使用出牌前的`playCost`。

审核场景也偏旧：单牌只测1／2敌、没有3敌；新噬能牌基本在0噬能下测试；资源准备牌常无合法消费出口；常规牌总是首张出牌，无法体现谢幕回旋／饭纲的启动条件。原组合工具仍只有7个旧主题、12项旧循环，未包含本次三组问题牌；多种子工具`ROUTES`也只有7条旧路线。

### P2：两张究极体牌缺少选择理由

| 牌 | 同形态、同费用比较 | 判断与建议 |
| --- | --- | --- |
| 深渊龙枪 | 2费、自损3；条件满足后22伤害、强化25，且耗竭。混沌枪击同样2费、自损3，无前置便有23／26伤害，命中生命还回复5，不耗竭 | 明显偏弱。耗竭可能带来减薄价值，所以不是所有场景严格劣势，但作为有条件爆发牌缺少回报。优先设计独特收益或让达标爆发明显超过混沌枪击 |
| 圣枪格拉墨 | 2费12＋⌊护盾/3⌋，强化15＋⌊护盾/3⌋；皇家枪击同费22／25并给8／11护盾，另可触发防御被动 | 护盾30才追平皇家枪击的伤害，仍无护盾收益；20盾时只有18／21伤害。高盾能超过但需要准备，定位不清。可考虑降低费用或提高盾转伤效率，再与通用盾击一起验算 |

不建议为了让所有卡U相等而一刀切增强。先确定它们是“高准备回报终结技”还是“稳定攻防循环”。

## 2. 需要验证的偏强候选

| 候选 | 已确认事实 | 当前判断 |
| --- | --- | --- |
| 疾风加农 | 本形态3噬能、0力量／0爆发／无进攻训练，基础对每个敌人23伤害、强化28；三敌总69／84，只花1行动力，非耗竭 | 高优先级偏强候选；含形态第3段起＋1伤害。必须把噬能准备成本及1／2／3敌差异一起测，不能只凭满载总伤害认定失衡 |
| 蝙蝠群袭＋ | 1费从3×3变成6×3，强化增加9总伤害；无其他加成时噬能获得1→2 | 升级回报跳跃明显；同为多段牌的加特林通常只增加3总伤害。完全体阶段允许更强，但应检查是否成为压倒性的强化首选 |
| 弗拉明戈斩＋、双重爪击＋ | 分别增加9／6总伤害，同时影响吸血／资源转化 | 属于升级规则不一致的风险，需按各自阶段和被动验证，不能只拿成长期牌横比 |
| 勇气咆哮＋、危险过载＋ | 前者同时降1费并加力量；后者同时多1行动力、多抽1 | 强化收益高但耗竭、自损能限制重复；先观察选取／强化集中度，不作为已证实无限循环 |
| 地狱咆哮＋ | 当前已是0费、非耗竭群体灼烧，与历史“保持1费”的调平结论不同 | 需要与末日审判、薄牌组、抽牌资源联测。本轮没有证明其能独立无限循环，不应把历史已解决结论直接套用 |

高速插件／净化程序、脉冲炮／后期炮击、防御插件／后期专属防御之间存在上位关系，不自动等于失衡。后阶段技能本就应成长；同阶段、同获取难度仍应有取舍。例如净化程序与高速插件费用、抽牌、耗竭相同，净化还会清故障，基本没有竞争缺点，属于可改善的内容差异化，而非优先级最高的数值漏洞。

其余卡本轮未找到同等明确的问题，不表示全部已通过平衡验收。103张牌都经过场景审核，完整覆盖表附于报告；最终判断仍需要修正模型与更多实战样本。

## 3. 公式如何保留与改进

现有公式：

`U = D + 1.25P + 2H + 3Q + 7ΔE + ΔF − 2L − 3N`

合理的部分：通过真实规则计算有效伤害、实际治疗、防伤和资源变化；忽略溢出；消费原有资源时扣估值；把组合序列作为整体看。这些优于只算面板伤害／费用。

局限：7点/费只是基础攻击锚点，不是所有回合的能量价格；多余且用不掉的能量价值低，能促成击杀的最后1费可能很高。抽牌受到手牌空间、牌组质量、剩余费用影响；治疗价值取决于剩余生命、旅途长度、恢复节点；固定剩余3回合也不适用于全部杂兵与首领。当前系数没有经过五章玩家数据拟合。

建议按以下顺序迭代：

1. **规则正确性**：统一基础／强化定义与实际出牌费用；补噬能、易伤、下次攻击加段及不同消费倍率；避免产出与消费双计。没有覆盖的效果标记“模型不支持”，不要给一个貌似精确的低分。
2. **循环判定独立于U**：识别可重复的牌堆／手牌结构及资源单调增长，分别报告所需牌数、升级数、准备成本和可兑现伤害／治疗。不能用U低或旧主题未超限来排除循环。
3. **同场景比较**：基础／强化、相同阶段和合法历史，1／2／3敌，0／3／6资源，首牌／启动后，短战／长战，缺血／满血，单牌／完整回合；报告区间及敏感性，而非一个全局排名。
4. **选牌与旅途验证**：扩展到11终点，让策略懂新机制和真实费用。做成对的“加这张牌／跳过／换同类牌”对照，记录胜率、有效失血、回合数、抽到却未使用率、资源浪费、选取与强化集中度。先保留权重作为占位，再用这些结果校准。

调整优先级：三个循环→评分与样本修复→两张弱究极体→偏强候选的定量调参。不要先对全卡池机械地统一增减伤害。
