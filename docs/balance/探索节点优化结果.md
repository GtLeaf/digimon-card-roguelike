# 探索节点优化结果

2026-10-10。解决五章地图补给密集、后期事件池耗尽与重复成长页面的问题。只调整节点结构和事件用途，保留现有战斗、卡牌、敌人及营地／磁盘的治疗数值。

## 当前规则

- 每章10层，每条实际可达路径4～6场战斗（含首领）、最多1商店、1～2营地，连续非战斗最多3层。教学首章两场齿轮兽保留，该章路径为5～6战。
- 每章有可达商店，首领前第9层固定营地；第4层额外营地直接接在精英之后。部分精英可以在营地和相邻宝箱之间选择；首战后允许进入相邻路线，后半段部分普通战可变线。全部边参加路径预算校验，商店不会直接通营地。
- 第一章第5层固定进化；后四章同层改为事件，第二章固定研究档案并且所有路径经过。成熟期、完全体、究极体的现有阶段门槛不变，后两阶段在首领奖励后衔接进化，营地提供补进化。
- 首领奖励后仅在存在开放阶段的合法后继时显示成长页。行为、资料或胜场不足仍能看条件与暂缓；没有后继阶段时直接进入祝福。最后一章仍进入胜利结算。
- 事件仅章内去重，跨章优先从未出现或最久未出现者；不再因没走的分支消耗全局唯一池。每章全部候选节点最多1个免费回血事件。

## 存档与构建

存档版本仍为3，无新存档字段。已有节点和next连线不重新生成，v1连接迁移仍用旧规则；旧无eventId节点继续使用原读卡器兜底。旧究极体进化点保留15%休整，地图标为休整营地；旧低阶段没有开放后继的成长点直接通过，不额外回血。具名旧事件读取当前统一设计，卡面与提示同步更新。

增加生成时的路径预算与孤立节点校验、候选池空值保护。新增审核入口：`npm run audit:exploration -- --label <新标签> --count 5`；支持`--baseline <冻结工程目录>`。输出禁止覆盖已有标签。

本轮主包越过500kB阈值后，将数码图鉴与伙伴图鉴改为打开弹窗时加载，仍使用既有界面与参数；新增JS块与其它正式资源一样进入完整PWA预缓存。
