# 探索路线优化结果

2026-10-11。采用明确分叉、局部汇合的稀疏路线结构，让选路在后续几层持续生效。适用于本轮代码中新开的旅途；已有存档的地图与连线继续保留。

## 地图规则

- 每章10层、3个起点，4种模板由两种节点布局及其镜像构成；每章有8或10条完整可达路径。
- 首战后沿原路线直行。普通节点1～2个出口；每条实际路径途中有1～3处分叉，相邻分叉至少间隔2层。左右相邻或节点同类型不再自动生成连线。
- 连线只能前往下一层；禁止X形交叉、重复连线与跨层跳跃。局部汇合最多2条支线，全路线统一汇合只发生在第9层首领前营地；首领后可重新选择下一章起点。
- 第5层采用3个等价入口：第一章为进化，第二章为研究，其他章节为同一事件。第8层也采用3个等价事件入口。玩家只经过其中一个入口、领取一次效果，路线在这些层保持方向。
- 同层等价入口可以共享事件ID，不同层不重复安排同一事件；每条实际路径不重复经历事件。每章最多1种免费回血事件；等价入口按一个事件机会计数，不增加同一路径的恢复次数。
- 每条路径维持4～6场战斗（含首领）、最多1商店、1～2营地，连续非战斗最多3层；额外营地直接跟在精英后，营地／商店互不相邻。教学首章保留两场齿轮兽，路径为5～6战。
- 挑战段提供较多精英与精英后的营地，经济段可进入商店，稳健段以普通战及宝箱为主；这些机会在模板和镜像中改变位置，节点内容仍使用现有遭遇与事件池。

生成时同时校验连线拓扑、所有章内路径预算、首领可达性、孤立节点和成长／研究入口。旧存档迁移继续使用旧版连接函数，读取已保存的v3节点不会重新生成连线。

## 地图交互

- 橙色节点为下一步可进入，点击直接出发；未相连的节点不能进入。
- 节点仅显示图标，不显示名称、描述或状态文字；已走过的节点和连线保留绿色，最后完成的节点以外圈标记当前位置。节点名称、描述和交互提示保留在无障碍标签中。
- 根据真实next连线计算后续可达范围，已经不能到达的未来支线淡化；统一汇合点仍保持可达。
- 未来可达节点点击可固定路线预览；鼠标悬停、键盘聚焦或触屏长按450毫秒可查看后续节点与绿色虚线。下一站长按后松手抑制出发点击；滑动超过10像素或触摸取消会停止长按计时。
- 预览只改变节点外圈和连线，不发送节点动作、不修改旅途进度。地图工具栏下直接显示地图，移除路线预览提示区与清除按钮；再次点击未来节点可取消固定预览，地图行进后清除预览。
- 地图页面沿用图鉴的按需加载方式；正式构建将新JS资源完整加入PWA预缓存。
