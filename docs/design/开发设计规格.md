# 开发设计规格

> 设计归档：本文包含早期目标和后续提案。当前已实现范围与数值见[项目说明](../项目说明.md)。

## Design Specification

1. Purpose Statement：为手机玩家制作可完整通关的数码兽卡牌冒险；先实现两位主搭档、五个终点和跨局扫描收集。敌人意图、出牌结果和进化收益必须一眼可读。
2. Aesthetic Direction：Retro-futuristic，掌机像素冒险与纸质收藏卡结合。像素角色置于有纵深的数码战场，界面用细边框、切角标签和数字刻度。
3. Color Palette：背景 #101d23、面板 #1c3037、纸卡 #f1ead9、行动色 #ef9958、数据色 #8dc9b4；危险色 #dd655b。
4. Typography：中文使用 PingFang SC、Microsoft YaHei，标题使用 Georgia，数字使用 Courier New；不依赖外部字体请求。图标使用 Lucide。
5. Layout Strategy：桌面为左侧旅程信息、中间战斗、右侧搭档状态的不对称布局；手机收拢为顶部资源、战场、底部横向手牌和固定操作条。地图由下向上、沿实际连线探索；进化树从左向右按阶段分列，成熟期开始分叉。手机横滑进化树，节点和卡牌详情使用底部面板，卡组使用全屏弹层。

## 本次交付边界

- React + TypeScript + Vite，本地单人游戏，不依赖账号或服务端。
- 三章各 8 层；战斗、精英、首领、营地、商店、事件、宝箱和进化选择。
- 基尔兽、妖狐兽；成熟期开始分支，共15种形态和5个究极体终点；本局行为与跨局资料共同决定路线资格；同步爆发为限时增益。
- 扫描、三种支援转化、跨局资料；完整状态和随机种子自动存档。
- 45 种基础／通用／搭档／路线卡，另设 1 种故障状态牌；6 种装置与 3 种祝福。
- 浏览器交互验证、战斗与进度逻辑测试、类型检查及正式构建。
