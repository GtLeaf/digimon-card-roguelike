# 第二轮平衡优化结果

> 历史记录：本文按各轮开发时的规则保留，数值与测试结果不自动适用于当前五章版本；当前规则见[项目说明](../项目说明.md)。

日期：2026-10-09。已完成公式v2、场景审核、多种子前后对照、3张牌调整和浏览器验收。真人完整构筑试玩及实体手机验收仍待完成。

## 本轮改动

| 卡牌 | 调整 | 理由与代价 |
| --- | --- | --- |
| 血色利刃／＋ | 13／16→16／19伤害 | 补偿3生命自损成本；保持1费及原有自损被动，增加输出也可能增加自损使用 |
| 小型龙卷风／＋ | 4／7→5／8群体伤害 | 小幅改善双敌用途；1费，扣费与出牌计数各一次 |
| 狐变虚＋ | 指定复制后追加抽1 | 改善支付复制费后的调度；仍1费，每回合所有来源合计2次，复制品耗竭 |

同形态的血色利刃基础牌实际伤害13→16，生命代价仍3。狐变虚＋复制并打出能量装填＋时，净能量仍＋1，新增可用牌1→2，序列U由4→7。该例说明定点收益改善，不能代表所有复制组合。

其他候选暂缓：灼烧／符印／蓄能的准备、消费与资源残留更依赖场景；没有足够证据支持全局加减数值。进化门槛与敌人数据不因本轮模拟结果改动。

## 校准与复现

[公式v2](../balance/卡牌平衡校准公式.md) 保留第一轮权重，改为支持完整出牌序列；终局不估值无用抽牌／返能／状态，支付成本保留。防伤从真实伤害反馈计算，排除胜利治疗重复得分。资源池共享剩余生命预算，消费出口排除耗竭牌；这些仍是明确场景假设，不是精确概率。

先修正固定策略中的非法复制、致死自损、强化选牌和来源估值问题，再冻结策略做正式基线；预跑不计入正式统计。两策略分别偏生存与协同，采用同一预算、真实引擎与公开路线条件，不以U作为唯一决策，不读取隐藏抽牌顺序。历史档案由7场连续真实行动取得，未手工赠送研究或扫描。

- 单牌：59张正常牌、1022项场景，[报告](../reports/card-balance-round2.md)。
- 组合：24复制序列＋340同形态单牌＋462主题回合＋12循环，共838项，[原始数据](../reports/combinations-round2.json)。有限场景无重复或超限，主题回合最多5次出牌，不证明所有卡组都不存在循环。
- 正式模拟：调参和独立种子各50个，7路线×2策略×新／历史档案，前后共5600局；0停滞、0超限，七终点既有通关回归通过。
- 新旧卡牌快照只有3张牌不同。[前后对照](../reports/balance-round2-comparison.md) 包含配对区间、每战净失血、回合数、取得时间、选牌／强化／使用及未达成路线诊断。

完整复现命令见公式第7节。`npm run audit:balance` 更新当前轮单牌报告；`npm run audit:combinations` 更新当前组合；`npm run audit:compare` 重建前后对照。旅途无label时写latest，不覆盖正式基线。第一轮报告与组合基线保留为历史快照。

## 对照结论与风险

| 种子组 | 总体通关前→后 | 目标终点通关前→后 |
| --- | --- | --- |
| 调参 | 1400→1400 /1400 | 1290→1291 /1400 |
| 独立验证 | 1400→1400 /1400 | 1291→1289 /1400 |

不能据此宣称总体难度明显改善。固定策略均能通关，胜率指标在这套策略下已经饱和；达成目标路线、失血和回合变化更有诊断价值。各组只有50种子，配对自助法区间仅描述固定策略差额，不代表玩家胜率。

独立验证中新档案、生存策略的混沌终点41→38/50；该组每战平均少0.128回合、净失血多0.278。下降的种子435587、768185、784023最终治疗均达到4次，但错过进化机会；调整前分别7／8／8次并已到达终点。血色利刃使用11→11、9→12、7→9。推测更快结束战斗压缩了及时治疗机会；行动也影响后续随机奖励，不能把全部差额归因于一张牌。JSON保存全部独立种子丢失终点的配对诊断。

因此保留这3张定点调整，同时将“有效治疗计数与最后补进化机会的关系”列为后续专项。葛叶兽双技能回合和晚达标也仍是未达成路线的主要原因。不要通过让模拟故意拖回合、降低门槛或只报告有利种子来掩盖问题。
