# 第二轮卡牌平衡优化计划

> 历史记录：本文按各轮开发时的规则保留，数值与测试结果不自动适用于当前五章版本；当前规则见[项目说明](../项目说明.md)。

日期：2026-10-09。基线：第一轮独立强化、复制每回合合计2次、154项测试，以及59张正常牌的502项场景校准报告。

目标：验证不同搭档和路线是否有稳定且有取舍的构筑，找出真正被替代、收益过高或容易形成重复操作的牌，并完成小批量、有前后对照的调整。执行状态：P0／P1已完成公式、场景、多种子对照与3张牌调整；P2已完成浏览器手机尺寸交互验收，真人完整构筑试玩和实体手机仍待完成。结果见 [第二轮平衡优化结果](第二轮平衡优化结果.md)。

## 2. 公式v2：先修正模型，保留第一轮权重作为基准

继续保留真实生命伤害、净行动力、实际治疗、按敌人意图测得的防伤值。第二轮不先用调权重的方式追求漂亮分数。

- **战斗结束边界**：胜利或死亡后，本场剩余力量、蓄能、灼烧、符印、额外抽牌与行动力的未来利用价值为0；支付成本仍记录。清场牌的评价应呈现胜利与避免攻击的结果。
- **复制与抽牌的后续收益**：单步Q继续只表示新增牌数量，不能据此判断狐变虚弱。新增短序列评估：支付复制费→获得指定牌→是否有能量与手牌空间使用→真实结算。复制返能、修复、阴阳术、攻击牌分别测；基础与强化比较同一手牌可选目标。序列初末计算一次资源差额，避免每步重复认领同一批未来状态。
- **消费出口与剩余战斗长度**：符印无出口、炮击无法支付、耗竭出口已用完分别估值；力量按剩余可命中段数审核。默认概率保留供对照，增加依据当前手牌／牌堆的明确场景，不将其包装成精确的获胜概率。
- **状态重叠与过量资源**：直接伤害、灼烧、符印共同受剩余敌方生命限制；长战T=5只是敏感性场景。避免将同一个剩余生命分别计为灼烧收益和符印收益。
- **生命与终局独立判定**：治疗、自损、胜利回复与反应伤害可能改变结束回合后的结果。记录生存／死亡、胜利、实际净生命变化，检查是否重复给胜利治疗防伤分。任何分数不得让致死自损成为优先选择。
- **附加指标**：破盾、清故障、耗竭减薄、进化进度、强化选择灵活性单独报告；暂不强行换算为统一点数。基础攻击的U为负表示资源基准下的边际分数，不等于它在开局无价值。

## 3. 构筑与完整回合场景

由真实引擎运行，人工构造的场景注明假设；路线技能只在实际解锁或明确继承时使用。共用牌在三位搭档及关键进化阶段分别测，不统一归到妖狐兽。

| 构筑 | 核心检查 |
| --- | --- |
| 基尔兽直接攻击／多段力量 | 双刃斩、勇气咆哮，进攻训练、力量、同步爆发与散热芯片的段数叠加 |
| 灼烧→引爆 | 火球、暗炎弹、地狱咆哮、烈焰引爆；短战是否来不及结算，长战是否过度堆层 |
| 混沌自损→恢复 | 危险过载、血色利刃、生命汲取、数据修复、混沌枪击；能量回收、生存成本与进化行为是否有真实取舍 |
| 妖狐兽符印→解印 | 符咒、狐叶楔、解印、净化之印；准备成本、消费频率、无出口时的负担 |
| 妖狐兽抽牌→复制／式神 | 灵视、分析、复制、阴阳术、管狐术；复制上限是否阻断回路且仍值得选 |
| 大耳兽连射 | 加特林、疾速射击、巨型导弹、爆裂射击；第二张攻击被动与每段加成 |
| 大耳兽防守→蓄能→炮击 | 蓄能指令、装甲装填、要塞整备、脉冲炮、定点轰击、重装齐射；消费出口与首张防御被动 |

场景维度包括：5／10／16张牌组、基础／关键牌强化、健康／半血／濒死、单敌／双敌、低血敌／高血敌、敌方无护盾／有护盾、准备回合／普通攻击／多段攻击／铁鸡兽反应／可打断重击。先使用有代表性的组合，避免无意义地遍历全部笛卡尔积。

循环搜索重点是“返能＋抽牌＋复制”，以及自损与恢复、力量与多段、符印与额外抽牌。记录所需牌数、强化数、形态、装置和准备成本。测试执行步数上限仅用作超时保护；达到上限标为待诊断，不视为平衡通过，也不向正式游戏加入总出牌次数限制。保留反例操作序列、资源轨迹和状态重复证据。

## 4. 多种子基线与前后对照

先修复模拟器：所有策略读取独立强化后的实际数值；选择合法目标；复制明确指定来源；排除达到复制上限的行动；没有可用动作时结束回合。若某步未推进状态，记录原因，不能静默卡死。

现有七终点回归继续作为路线可达性检查。另建立统一、可复现的评估策略，不用第一轮U作为唯一决策目标：一套偏生存／资源效率，一套偏路线核心协同。奖励与强化规则预先固定，设置相近卡组／消费预算；普通牌和清故障不会被路线偏好无限压低。除指定路线目标外，不硬塞牌、金币、研究、行为计数或生命。

第一阶段：固定50个种子×7个终点×2套策略，共700次基线运行。发现异常后，用同一种子集、同一策略和同一预算复测候选改动；再用独立的50个种子验证。新玩家未解锁与已解锁研究状态分组，不混合计算；无法取得必要研究算目标路线未达成，不伪造资料。

记录：目标终点达成率、整体通关率、死亡章节／敌人、每战净失血、战斗回合数、单回合出牌次数的P95及最大值、复制次数、无效符印／蓄能残留、牌组张数、奖励跳过、强化选择、核心牌取得时间、是否依赖特定装置。机器人选牌／强化频率只表示该策略的偏好，不能当玩家喜好。

前后对照以固定种子配对，附运行次数及不确定性范围。同种子不同路径与行动会改变随机调用及后续奖励，并不保证后续抽牌完全相同；战斗快照的定点复测用于补充控制变量。

## 5. 优先复查卡牌与可能方向

以下是候选审核名单，不预先决定最终数值。

| 候选 | 当前疑点 | 第二轮决策依据／可能方向 |
| --- | --- | --- |
| 狐变虚／狐变虚＋ | 单牌报告无法体现复制目标效果，两次上限可能限制普通构筑 | 比较复制返能、治疗、能力、攻击的完整序列；若普遍无收益，优先改善可用目标与强化价值，保持资源回路约束 |
| 紧急分析／灵视／高速插件 | 免费耗竭抽牌与付费重复抽牌的用途差别 | 长战、薄／厚牌组及手牌上限；分析是否能稳定搜索核心牌，再决定抽牌或费用取舍 |
| 数据修复／生命汲取 | 第一轮恢复费用变化影响持续性与混沌路线门槛 | 每章净回复、复制恢复收益、濒死操作和有效治疗次数；避免削弱后路线难以取得行为资格 |
| 防护屏障／金刚结界／战术整备 | 单纯大护盾可能被抽牌／复合防御取代 | 大攻击、多段、护盾溢出、祝福和盾击收益；若同阶段长期被替代，再增强专属用途 |
| 血色利刃 | 付出生命的伤害优势是否足够 | 黑古拉兽同阶段可选攻击比较，计入未来协同与实际自损成本；若协同外仍显著吃亏，可提高输出或增加有限补偿 |
| 小型龙卷风／炽热气弹 | 大耳兽初始牌在单敌时价值偏低 | 真实第一章遭遇分布、起手失血、蓄能准备；确认是否需要小幅改善单体用途 |
| 地狱咆哮／灭世烈焰 | 双敌、形态灼烧加成与长战的收益明显放大 | 按实际战斗长度和灼烧结算时点复测；若过强，再选择费用／耗竭／叠层的一项调整 |
| 重装齐射／定点轰击／巨型导弹 | 高蓄能倍率与多段力量协同的竞争 | 相同形态、0／3／6蓄能、相同力量／训练，比较瞬间输出与耗竭后的续航 |

第一次候选改动控制在约3～5张证据充分的牌。优先解决同阶段、同代价的用途被全面替代；不要为了统一分数抹平攻击、控制、状态和成长阶段差异。一次尽量只改变费用、单项数值或限制中的一类，以便归因。

## 6. 验收与人工体验

- 154项原有测试继续通过，新增公式边界、组合序列、资源回路和异常策略诊断测试。规则／费用／文案一致，旧档与回合中保存继续兼容。
- 七终点真实行动回归继续可达；多种子前后对照不得出现未经解释的章节失血、停滞或目标路线可达性退化。
- 某路线通关率相差约10个百分点、某张牌在公平对照中持续被替代、或长回合异常增加时，进入人工复查；这些是预警线，不是必须削平的目标。
- 至少覆盖三位搭档与复制、灼烧、混沌、炮击构筑的人工试玩；记录拿牌理由、强化选择、状态出口与复制两次限制是否自然。人类试玩结果不能由机器人替代。
- 手机重点验证复制选择／剩余次数、清故障、状态消费、强化预览与长回合操作；真机条件不足时明确列为未验收。

最终交付：公式v2、组合／循环报告、多种子基线和前后对照、第二轮卡牌变更表、试玩记录与尚未解决的问题。完成第一轮基线后再确认具体调参数值，不预先声称第二轮已平衡。
