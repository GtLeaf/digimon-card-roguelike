日期：2026-10-09。检查当前工作区的生产构建，使用独立浏览器存储，不修改日常试玩或正式站点的存档。

2026-10-10补充：正式站点桌面Chrome全新存储访问可完成缓存（本机网络约两分钟）；网络检查曾出现单个资源连接失败，尚未确认用户浏览器中的具体失败原因。已补充首次准备失败时最多两次自动重试，保留已下载资源；持续失败后允许手动重试，缓存完整后清除旧失败提示。成功安装的旧worker被新版替换时不再误报下载失败。

新增浏览器回归模拟首次资源返回503后自动恢复，以及连续503时恰好三次下载尝试后停止，手动重试成功。连同已有离线读档、导入、更新与浏览器冷启动，共10组验收通过；类型检查、静态检查及生产子路径构建通过。

## 已实施

- `vite-plugin-pwa`生成安装清单与完整预缓存；HTML、JS、CSS、所有运行时图片／动画、安装图标及来源声明一并缓存。
- 通过实际资源清单检查完整性，完成后才显示“已可离线游玩”；首次下载失败可重试。
- 每次生产构建在Service Worker生成后核对完整清单；资源遗漏或因大小限制跳过时构建失败，避免发布残缺离线包。
- GitHub Pages子目录作为应用作用域，主屏幕独立窗口配置与192／512、maskable、Apple图标已生成。
- 新版后台下载后等待确认；战斗阶段不更新，保存失败不切换，多游戏窗口阻止激活，其他项目窗口不受影响。
- 存档JSON导入复用迁移逻辑，限制2MB，预览后明确确认，先备份原记录，重新初始化对局和动画队列。取消、无效内容、存储失败与预览后进度变动均不覆盖原存档。

## 浏览器验证

运行 `PWA_BROWSER_CHANNEL=chrome npm run test:offline`，在生产子路径 `/digimon-card-roguelike/` 下检查：

1. 所有运行时资源都进入预缓存，安装入口和作用范围正确。
2. 真实界面开局、出牌后，关闭页面并断网重启／刷新，恢复相同游戏状态和随机状态；断网逐一读取全部资源。
3. 离线导入时错误文件与取消不改存档，确认后保存原记录并恢复备份战斗，战斗内禁用导入。
4. 模拟新版资源下载失败，旧版仍可离线重启；重试成功后等待确认。
5. 更新在战斗中禁用，多游戏窗口阻止切换；关闭其他游戏窗口后保存更新，其他项目窗口不受影响，新版可以离线重启。
6. 离线开始新局，320／390px设置界面无横向溢出。
7. 离线敌方行动与下回合刷新恢复正常。
8. 首次下载不完整不显示就绪，重试可恢复离线使用。
9. 关闭整个浏览器进程后，使用保留的独立资料目录断网冷启动，恢复原进度。

精确浏览器版本、资源数量、结果与未捕获异常列表见[验证数据](verification.json)。截图：[首页390px](home-390.png)、[设置320px](settings-320.png)、[设置390px](settings-390.png)。

另验证了默认根路径构建的完整缓存、作用范围与断网刷新；设置弹窗的键盘焦点跳过隐藏文件输入并留在弹窗中。当前工作区424项自动测试、类型检查、静态检查、格式检查与生产构建通过。
