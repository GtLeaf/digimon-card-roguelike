# 手机版旅途交互优化

商店、营地、六种事件和旧存档事件采用「点选预览 → 明确执行」方式；战后奖励点卡直接领取并继续旅程。界面沿用深青、纸色、橙色与薄荷绿的数码终端风格。

## 交互变化

- 手机商品与奖励卡牌采用紧凑展示；商店点选查看详情，奖励卡牌直接展示效果，点卡即领取，不再显示领取弹窗或「查看效果」按钮。
- 购买预览显示价格、已有同名牌数量，不显示购买后余额；确认后展示真实获得的卡牌、磁盘或装置名称与效果。
- 删牌、营地强化、事件强化／删牌使用独立面板；支持类型筛选与准确选择同名牌中的一张。强化效果来自正式卡牌配置，展示前后费用和效果。
- 选牌面板单独滚动；短屏仍保留确认与取消。支持 Escape、焦点约束、关闭后恢复焦点与原页面位置。
- 商店／营地离开、奖励跳过位于手机版固定底栏，适配底部安全区；生命与金币栏滚动时保留。
- 不足金币、磁盘已满、已购买、已精简、牌组至少保留五张等情况展示具体原因。无法执行的事件不展示不可实现的资源变化。
- 恢复磁盘购买后增加库存，在战斗中使用时回复最多18生命；营地按实际缺血量展示回血收益，满血禁用恢复，并允许离开营地。
- 事件预览展示实际生命／金币变化，标明本局训练与跨局永久资料；旧事件使用同一套预览和反馈。
- 奖励扫描可展开查看和转化伙伴；跳过卡牌仍保留已获得资源。

## 验收方式

自动测试覆盖购买不直接回血、重复提交、随机装置实际反馈与存档恢复、同名牌精确移除、最低牌组数量、营地满血／离开、回复上限与生命消耗下限、不可执行事件和奖励跳过。

浏览器验收使用 `tests/manual/interactions.html` 与正式 App、正式规则。该夹具仅允许在5179端口写入测试存档，不进入正常生产入口；可构造长牌组、低金币、满血、满磁盘、六种事件与旧事件。分别检查320×568、390×844和桌面1280×900；重点验证取消不扣费、底部按钮可见、强化前后效果、实际资源变化、扫描伙伴转化及无整页横向溢出。

检查以浏览器响应式视口为准，尚未进行实体iOS／Android手机验收。

2026-10-09验收结果：187项测试通过，静态检查和包含TypeScript检查的生产构建通过。浏览器验证了预览／取消不扣费、购买与随机装置结果、32张牌滚动与精确删牌、事件强化扣费、实际回血、满血离开、奖励领取／跳过／伙伴转化、六类事件及旧事件永久资料解锁。320px与390px无整页横向溢出，短屏确认／取消仍在可视范围；独立构建预览无浏览器错误。实际截图保存于工作文档目录下的「旅途交互预览」。
