# 当前项目说明

版本：v0.3.0；更新：2026-10-12。当前规则以本文件和代码为准；启动与发布方法见[项目入口](../README.md)，历史提案与验证记录见[文档索引](README.md)。

## v0.3.0 本轮改动

- 首页显示版本统一读取 `package.json`，展示完整版本号；修复升级后仍显示0.2的问题。
- 探索地图采用4种稀疏路线模板，只在明确分叉处变线，禁止X形交叉；第5、8层使用等价入口，首领前营地统一汇合。支持后续路线预览与不可达支线淡化。
- 探索路线每章4～6战、最多1商店、1～2营地、连续非战斗最多3层；实际路径内事件去重，同层等价入口可以共享事件；额外营地紧接精英。
- 收敛免费回血事件；数据之泉改为生命换指定删牌，黑市改为生命与金币换指定强化；成长页按后继进化机会显示。
- 第二章别西卜兽采用18／15／21／装填四拍，18点直接生命伤害可将炮击压制至14；狂暴按整次行动分配，状态与伤害预告实时刷新。
- 沿用存档v3和已有地图；新地图规则仅用于新开局。完整验证见[探索节点优化结果](balance/探索节点优化结果.md)与[第二章首领优化结果](balance/第二章首领优化结果.md)。

战斗操作：第一次点击手牌选中卡片，第二次点击同一张牌直接使用；也可点击「使用」按钮。需要指定目标时先点击敌人。出牌与敌方行动按顺序播放简短动效，命中时结算；手牌横向滑动，结束回合前可使用支援或恢复磁盘。抽牌堆按名称／费用排序展示，不暴露真实抽取顺序。

基础牌定位：「攻击指令」保留在四位搭档的初始牌组，可正常使用、强化或移除，但不再进入战后奖励与商店。旧存档中已持有或已购买的攻击指令保留；尚未领取／购买的候选在加载时替换为合法卡牌，不改变随机状态。「防御插件」仍可获取；「岩石粉碎」为1费9伤害、强化12伤害。

大古拉兽进化赠牌为「余烬护甲」与专属「炎核重炮」。炎核重炮是本游戏自定义技能：2费12伤害、施加4灼烧；强化后基础伤害15，其他效果相同。到达大古拉兽后开放奖励／商店，后续进化保留为继承技能。通用脉冲炮及大耳兽初始牌组保留；已经进化的旧存档保留原有牌，不自动替换或补发新赠牌。

大古拉兽新增专属「熔火增幅」（2026-10-12）：1费技能，使所选目标已有灼烧精确翻倍，耗竭；强化后0费。到达大古拉兽后进入奖励／商店，后续进化继承，不额外占用进化的两个赠牌名额。纯状态技能不被护卫转移；目标没有灼烧时仍为0，不触发首次实际灼烧护盾。实际增加灼烧可触发首次灼烧被动与防火模块，但翻倍不叠加火种徽章、继承或形态的首次额外灼烧层数，可继续接烈焰引爆或圣炎之盾。

贝尔菲兽「沉睡」（2026-10-12）每次额外回复自身6生命，不超过最大生命；意图预告与实际结算共用自疗目标规则，不会转而治疗缺血更多的同伴。保留16护盾、前两回合沉睡与第三回合觉醒，觉醒回合不回血。

临时避难所（2026-10-12）改为「休息／离开」，点击直接执行。休息先回复18生命（不超过上限），再抽取一次结果：70%平安，20%被碎屑砸伤并失去8生命（最低保留1生命），10%丢失1枚恢复磁盘；没有磁盘时明确提示没有物品可丢失。结果页展示实际回复、意外及最终资源，底部「离开」继续旅程；预览不抽取结果，读档与重复点击不重复结算。直接离开无收益／损失，也不消耗随机状态。

本次新增23项机制回归通过，包含新卡精确翻倍与连招、沉睡自疗与预告、避难所三种随机结果与读档防重复；相关133项测试、生产构建、静态检查与差异格式检查通过。全量测试中的既有混沌路线固定策略仍通关4／10，未达到5／10门槛，失败种子仍为2、4、7、8、9、10。浏览器已验证避难所两项直接选择、结算结果与底部离开继续探索。

卡片图鉴检索（2026-10-12）：数码图鉴的卡片页支持关键词搜索、多选分类和机制标签。搜索默认收起为工具条上的图标，点击后展开输入框，「收起」会清空关键词。关键词可搜卡名、效果、强化后效果、形态名与机制词，空格分隔的多个词需同时命中；忽略空白与全角半角差异，并支持群攻、吸血等同义词。分类包括搭档（快捷条）、来源形态、成长阶段、类型与费用；机制标签由卡牌配置推导，资源类区分产生和利用（如灼烧·施加／灼烧·利用）。各选项显示分面计数，结果为空时提示可放宽的条件。「强化版」开关让卡面、费用、标签与搜索按强化后计算。点击卡片打开详情，包括强化对比、来源、获取方式、可点击的机制标签、产生↔利用搭配参考与进化树定位；有进行中的冒险时，还可按「卡组中／本局可获取」筛选。未收录卡仍可按卡名、效果与机制检索，但不按形态名命中、不参与形态筛选，详情也不显示所属形态。检索条件在关闭图鉴后保留，刷新后重置，不写入存档。规则与验收见[卡片图鉴检索方案](design/卡片图鉴检索方案.md)。

首页操作：点击搭档选择位切换角色与玩法介绍，再点击「与搭档出发」进入旅途祝福；查看进化路线会打开当前选中的搭档。有进行中的冒险时，首页展示当前形态、章节、生命和卡组，点击「继续冒险」返回原进度。数码图鉴、伙伴图鉴、道具图鉴与玩法说明位于主操作下方，设置保留在顶部。手机短屏优先展示选择与出发，辅助入口可向下滚动查看。

旅途交互：商店装置点击后弹窗展示效果，再确认购买；金币不足或已拥有的装置也能查看效果。卡牌与恢复磁盘点击直接购买，训练终端和流浪补给商选项点击直接执行。回响信号仅展示选项名称，点击后显示实际结果，底部「离开」返回地图；已结算状态随存档保留，刷新或重复点击不会重复领取。删牌／强化使用独立选牌面板，支持类型筛选、完整效果与强化前后对比；取消不扣费且保留原页面位置。手机版固定金币／生命状态和底部确认、取消或离开入口；不足金币、满容量与已购状态直接说明原因。恢复磁盘购买后进入库存，在战斗中使用回血；营地显示实际回复量，满血不消耗恢复行动，可直接离开。扫描详情可展开，跳过卡牌仍保留金币、扫描和已转化伙伴。详见 [手机版旅途交互优化](ui/手机版旅途交互优化.md)。

2026-10-11界面精简：移除地图顶部的操作说明；数码兽名称后展示属性图标，水滴／尖刺球／立方体／问号对应疫苗／病毒／数据／未知，悬停与读屏保留属性名称。三枚主要属性符号采用[The Digital Empire的Cyber Sleuth图标矢量重绘](https://thedigitalempire.net/projects/graphics/#attributes-cyber-sleuth)，并非官方原始文件；未知、未标注、不适用属性沿用现有符号，仅改变展示，不改规则与数值。伙伴支援演出点击任意位置跳过，支持回车、空格和Escape，不再显示独立跳过按钮。浏览器验证装置查看／返回／购买、训练与补给直接执行、回响结果刷新与离开、支援点击与键盘跳过；320／390／1280px无横向溢出。完整测试494／495通过，唯一失败仍为前述混沌路线通关率检查；构建与静态检查通过。
