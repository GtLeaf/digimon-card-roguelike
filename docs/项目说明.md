- 探索路线每章4～6战、最多1商店、1～2营地、连续非战斗最多3层；事件章内去重，额外营地紧接精英。

- 第二章别西卜兽采用18／15／21／装填四拍，18点直接生命伤害可将炮击压制至14；狂暴按整次行动分配，状态与伤害预告实时刷新。
- 沿用存档v3和已有地图；新地图规则仅用于新开局。完整验证见[探索节点优化结果](balance/探索节点优化结果.md)与[第二章首领优化结果](balance/第二章首领优化结果.md)。

战斗操作：第一次点击手牌选中卡片，第二次点击同一张牌直接使用；也可点击「使用」按钮。需要指定目标时先点击敌人。出牌与敌方行动按顺序播放简短动效，命中时结算；手牌横向滑动，结束回合前可使用支援或恢复磁盘。抽牌堆按名称／费用排序展示，不暴露真实抽取顺序。

基础牌定位：「攻击指令」保留在四位搭档的初始牌组，可正常使用、强化或移除，但不再进入战后奖励与商店。旧存档中已持有或已购买的攻击指令保留；尚未领取／购买的候选在加载时替换为合法卡牌，不改变随机状态。「防御插件」仍可获取；「岩石粉碎」为1费10伤害、强化13伤害。

大古拉兽进化赠牌为「余烬护甲」与专属「炎核重炮」。炎核重炮是本游戏自定义技能：2费12伤害、施加2灼烧，消耗全部蓄能、每层额外4伤害；强化后基础伤害15，其他效果相同。相比通用脉冲炮少2点即时伤害，换取灼烧、首次实际灼烧护盾与引爆配合。卡面使用已有大古拉兽素材，到达大古拉兽后开放奖励／商店，后续进化保留为继承技能。通用脉冲炮及大耳兽初始牌组保留；已经进化的旧存档保留原有牌，不自动替换或补发新赠牌。

首页操作：点击搭档选择位切换角色与玩法介绍，再点击「与搭档出发」进入旅途祝福；查看进化路线会打开当前选中的搭档。有进行中的冒险时，首页展示当前形态、章节、生命和卡组，点击「继续冒险」返回原进度。数码图鉴、伙伴图鉴、道具图鉴与玩法说明位于主操作下方，设置保留在顶部。手机短屏优先展示选择与出发，辅助入口可向下滚动查看。

旅途交互：商店、事件、营地与战后奖励统一先预览、再明确执行。删牌／强化使用独立选牌面板，支持类型筛选、完整效果与强化前后对比；取消不扣费且保留原页面位置。手机版固定金币／生命状态和底部确认、取消或离开入口；不足金币、满容量与已购状态直接说明原因。恢复磁盘购买后进入库存，在战斗中使用回血；营地显示实际回复量，满血不消耗恢复行动，可直接离开。扫描详情可展开，跳过卡牌仍保留金币、扫描和已转化伙伴。详见 [手机版旅途交互优化](ui/手机版旅途交互优化.md)。

2026-10-10探索节奏调整：免费回血事件仅保留读卡器／避难所／数据泉，原治疗数值与营地、磁盘治疗值不变；数据泉可用生命换指定删牌，黑市可用生命与金币换指定强化。首领奖励只在后继阶段开放且仍有合法进化时展示成长页，未满足行为／资料条件仍能查看进度与暂缓；营地补进化作为补救。已有存档保留原节点及连接，旧无事件ID的兜底与究极体15%休整继续兼容。完整规则和验证见[探索节点优化结果](balance/探索节点优化结果.md)。

## 2026-10-09 敌人 AI 校准

伤害预告考虑前序敌人的鼓舞、治疗和召唤，与实际结算共用行动效果；玩家击杀增益者、打断蓄力或触发半血变招后重新预告。散射和普通攻击统一按每张牌对每个实际损失生命的敌人计一次有效攻击，多段不重复计数，全格挡不计，致死命中计数。

别西卜兽采用四回合循环：连续射击6×3、压制射击5×3、死亡加农21、装填12护盾；装填回合不攻击、不积攒噬能。炮击当回合对其造成18点直接生命伤害，可将本次加农基础伤害21降至14，进度与结果实时显示；护盾吸收和灼烧持续伤害不计入。第三章车棋兽＋白兵棋、相棋兽＋白马棋形成固定双人精英编队，生命／伤害按整队预算缩放。“流水线三班”固定错开相位，无干预前三回合合计伤害从 `0→36→36` 调整为 `20→20→20`。

第五章贝尔菲兽睡眠护盾20降至16，觉醒总伤害45降至39；第四章莉莉丝兽穿透14降至12，第五章灭世魔兽穿透21降至18。核心召唤的复制体鼓舞改为全体每段＋1，力量上限6；原生复制体仍全体＋2。究极魔兽和巴鲁巴兽的成长明确只作用于自身。保留召唤上限与入场待机。别西卜兽第13～14回合每次攻击行动总伤害＋3，第15回合起＋6，连射平均分配；其他首领保留第13回合起每回合每段＋2、最多＋6的软狂暴。

敌人状态条显示力量、护卫、别西卜兽噬能、软狂暴与关键爆发倒计时。新地图的编队修正与战斗状态写入现有v3存档；旧节点不重新生成，缺少修正字段时默认原始数值与相位。执行 `npm run audit:enemies -- --label <标签>` 可生成固定场景审核；结果见[敌人 AI 优化与验收](balance/敌人AI优化结果.md)。

第二章首领2026-10-10专项调整与验证见[第二章首领优化结果](balance/第二章首领优化结果.md)。复用已保存的直接伤害计数，不新增存档字段或版本；旧存档噬能触发的提前加农同样可以压制。

## 2026-10-09 合并校准与五章版本

本地 `828627d` 与远端 `3951abb` 整合：沿用远端五章、第四搭档、新敌人、图鉴、存档 v3 和拆分后的引擎；保留本地校准公式、独立强化、复制选择与上限、基尔兽特性连贯性以及首页／旅途／进化替换交互。

现有107张卡共用最终强化配置。每次进化固定两个卡牌奖励名额，组合为赠送两张新形态卡、强化一张旧招式并赠送一张新形态卡，或强化两张旧招式。新赠牌均为未强化版；旧招式每个名额只强化一张尚未强化的现有拷贝，不会强化全部同名牌。原卡已删除或已全部强化时，改送另一张新形态卡，优先选择牌组尚未拥有的招式，不会占用另一个奖励名额的新招式。预览与结算共用同一确定性计划，不消耗随机状态。古拉兽默认强化一张火球并赠送双刃斩；九尾狐兽默认各强化一张狐叶楔和符咒；巫师兽只赠冰晶魔法和魔术屏障，不额外批量强化旧牌。形态被动、训练与继承仍按各自规则结算。此前三章、60张卡及4800／5600局报告均为历史归档，不代表当前五章版本胜率。

进化树浏览中的「招牌卡片」只展示选中形态的专属与共享技能，卡面标明技能归属；实际进化的两个奖励名额另按当前牌组预览，可包含旧形态招式的强化。例如古拉兽招牌展示双刃斩、热浪与共享的烈焰引爆，不将基尔兽的火球列为古拉兽招牌。

黑大古拉兽新增专属「黑暗过载」和「暗黑汲取」，作为两张新形态赠牌，分别沿用危险过载与生命汲取的基础及强化数值，到达该形态后进入奖励／商店卡池，后续进化保留为继承技能。原有危险过载、通用生命汲取及其获取规则保留；已有存档不自动替换或补发新卡，新规则从下一次进化开始生效。

合并回归保留308项测试，迁移旧数值及进化门槛断言；旅途策略支持新休整节点、公开自损／治疗条件与补给购买，不修改旅途资源或游戏难度来保证通关。完整测试、静态检查和构建通过。浏览器在独立5193端口验证首页图鉴入口、进化两槽预览与实际提交。
