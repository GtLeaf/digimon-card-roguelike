战斗操作：第一次点击手牌选中卡片，第二次点击同一张牌直接使用；也可点击「使用」按钮。需要指定目标时先点击敌人。出牌与敌方行动按顺序播放简短动效，命中时结算；手牌横向滑动，结束回合前可使用支援或恢复磁盘。抽牌堆按名称／费用排序展示，不暴露真实抽取顺序。

基础牌定位：「攻击指令」保留在四位搭档的初始牌组，可正常使用、强化或移除，但不再进入战后奖励与商店。旧存档中已持有或已购买的攻击指令保留；尚未领取／购买的候选在加载时替换为合法卡牌，不改变随机状态。「防御插件」仍可获取；「岩石粉碎」为1费10伤害、强化13伤害。

大古拉兽进化赠牌为「余烬护甲」与专属「炎核重炮」。炎核重炮是本游戏自定义技能：2费12伤害、施加2灼烧，消耗全部蓄能、每层额外4伤害；强化后基础伤害15，其他效果相同。相比通用脉冲炮少2点即时伤害，换取灼烧、首次实际灼烧护盾与引爆配合。卡面使用已有大古拉兽素材，到达大古拉兽后开放奖励／商店，后续进化保留为继承技能。通用脉冲炮及大耳兽初始牌组保留；已经进化的旧存档保留原有牌，不自动替换或补发新赠牌。

首页操作：点击搭档选择位切换角色与玩法介绍，再点击「与搭档出发」进入旅途祝福；查看进化路线会打开当前选中的搭档。有进行中的冒险时，首页展示当前形态、章节、生命和卡组，点击「继续冒险」返回原进度。数码图鉴、伙伴图鉴、道具图鉴与玩法说明位于主操作下方，设置保留在顶部。手机短屏优先展示选择与出发，辅助入口可向下滚动查看。

旅途交互：商店、事件、营地与战后奖励统一先预览、再明确执行。删牌／强化使用独立选牌面板，支持类型筛选、完整效果与强化前后对比；取消不扣费且保留原页面位置。手机版固定金币／生命状态和底部确认、取消或离开入口；不足金币、满容量与已购状态直接说明原因。恢复磁盘购买后进入库存，在战斗中使用回血；营地显示实际回复量，满血不消耗恢复行动，可直接离开。扫描详情可展开，跳过卡牌仍保留金币、扫描和已转化伙伴。详见 [手机版旅途交互优化](ui/手机版旅途交互优化.md)。

## 2026-10-09 敌人 AI 校准

伤害预告考虑前序敌人的鼓舞、治疗和召唤，与实际结算共用行动效果；玩家击杀增益者、打断蓄力或触发半血变招后重新预告。散射和普通攻击统一按每张牌对每个实际损失生命的敌人计一次有效攻击，多段不重复计数，全格挡不计，致死命中计数。

别西卜兽改为四回合循环：三连射、三连射、死亡加农、装填12护盾；装填回合不攻击、不积攒噬能。第三章车棋兽＋白兵棋、相棋兽＋白马棋形成固定双人精英编队，生命／伤害按整队预算缩放。“流水线三班”固定错开相位，无干预前三回合合计伤害从 `0→36→36` 调整为 `20→20→20`。

第五章贝尔菲兽睡眠护盾20降至16，觉醒总伤害45降至39；第四章莉莉丝兽穿透14降至12，第五章灭世魔兽穿透21降至18。核心召唤的复制体鼓舞改为全体每段＋1，力量上限6；原生复制体仍全体＋2。究极魔兽和巴鲁巴兽的成长明确只作用于自身。保留召唤上限、入场待机和首领第13回合起每段最多＋6的软狂暴。

敌人状态条显示力量、护卫、别西卜兽噬能、软狂暴与关键爆发倒计时。新地图的编队修正与战斗状态写入现有v3存档；旧节点不重新生成，缺少修正字段时默认原始数值与相位。执行 `npm run audit:enemies -- --label <标签>` 可生成固定场景审核；结果见[敌人 AI 优化与验收](balance/敌人AI优化结果.md)。
